
# GPT Backend

A backend project for a GPT-style AI chat application built with Node.js and Express.

## GitHub Repository

🔗 **Repository:**[https://github.com/DipanPramanik098/GPT-Backend](https://github.com/DipanPramanik098/GPT-Backend)

## Clone the Project

```
git clone https://github.com/DipanPramanik098/GPT-Backend.git
cd GPT-Backend
```

## Main Features

* User authentication
* Chat creation and management
* AI message generation
* OpenRouter API integration
* Chat history
* Token usage tracking
* Chat summarization
* MongoDB database integration

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* OpenRouter API
* JWT Authentication
